# Variables in C#

## Introduction

Variables are used to store data in memory.
They help make applications dynamic and reusable.

## Why Variables Are Important?

- Store user data
- Perform calculations
- Manage application state
- Used in every program

## Real-Life Example

Think of a variable like a storage box.

A labeled box stores specific items.
Similarly, a variable stores specific data.

## Syntax

```csharp
datatype variableName = value;
```

#  Code Example


## Example

```csharp
string name = "Umang";
int age = 21;

Console.WriteLine(name);
Console.WriteLine(age);
```

#  Output


## Output

```
Umang
21
```

## Explanation

- `string` stores text values
- `int` stores integer numbers
- `Console.WriteLine()` prints output

## Common Data Types

| Data Type | Description | Example |
|---|---|---|
| int | Integer | 10 |
| string | Text | "Hello" |
| bool | True/False | true |
| double | Decimal | 10.5 |

## Important Notes

- Variable names should be meaningful
- C# is case-sensitive
- Initialize variables properly
